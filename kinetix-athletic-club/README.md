# KINETIX Athletic Club - Web Application

A responsive web application for KINETIX Athletic Club featuring:
- Interactive weekly class schedule with discipline and day filtering
- Class reservation system with instant digital confirmation passes
- Master trainer profiles with certifications, focus areas, and assessment booking
- Membership plan selector with flexible monthly / annual billing calculations
- Dynamic registration flow generating member credentials
- Verified member outcome testimonials and statistics
- Direct concierge contact with one-click phone and email routing
- Dark mode and light mode toggle with persistent theme preference
- Fully responsive layout built with React, TypeScript, and Bootstrap 5

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
1. Extract the zip file and navigate into the directory:
   ```bash
   cd kinetix-athletic-club
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit:
   ```
   http://localhost:5173
   ```

### Building for Production
To generate an optimized production build:
```bash
npm run build
```

The output will be in the `dist/` directory, ready to deploy to Vercel, Netlify, GitHub Pages, or any web host.
